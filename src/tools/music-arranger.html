整曲
歌曲 = 段落时间线。每个段落引用一个“片段”，并设定启用哪些层与动态(滤波开合 / 淡入淡出 / 段尾自动 Riser / 段首 Impact)。把顶部切到“整首歌曲”播放，即按前奏→主歌→铺垫→高潮→尾奏顺序连成完整曲子。点段落块可选中并在下方编辑。
添加段落
多声道 · 场景 —
Wwise 式互动音乐:把各片段(pattern)的层拆成可开关的声道,用场景控制哪些声道在响(垂直分层),并可把声道绑定到不同 pattern 的内容(横向切段)。切换在下一小节同步生效并带淡入淡出。游戏里只需调 setScene / setChannel / setRTPC 即可渲染不同主题气氛。改完编曲点“刷新”重建声道。
